Tema: CalendarioApp - agenda de eventos con acceso restringido.
Tablas: usuario (login) y evento (CRUD). La tabla evento usa una columna
POINT (ubicacion: longitud/latitud) y una columna JSON (detalle).

CONTENIDO
  calendario_bd.sql   Script SQL (S1-S5): base, tablas y datos de prueba.
  CalendarioApp/      Proyecto NetBeans (Java with Ant, JDK 21).
                      Driver: CalendarioApp/lib/mysql-connector-j-26.10.0.jar

COMO EJECUTAR
  1. Ejecutar calendario_bd.sql en MySQL (Workbench, phpMyAdmin o consola).
  2. Abrir CalendarioApp en NetBeans: File > Open Project.
  3. Si MySQL tiene clave para root, cambiarla en src/conexion/Conexion.java
     (constante CLAVE). La URL apunta a localhost:3306/calendario_app.
  4. F6 para ejecutar. Alt+F6 para las 24 pruebas JUnit 4.
